# 오늘도 딴다

도로교통공단 2종보통 학과시험 문제은행 **1,000문항**으로 하루 10문항씩 학습하는 웹앱.
홈 화면에 추가하면 앱처럼 열리고 오프라인에서도 동작한다.

## 기능
- **오늘치 10문항** — 안 푼 문항을 먼저 소진해 1,000문항을 한 바퀴 돈다
- **오답노트** — 다시 맞히면 목록에서 자동으로 빠진다
- **영역별 학습** — 7개 영역의 오답률을 집계해 약한 영역만 골라 푼다
- **실전 모의고사** — 40문항·40분. 실제 시험처럼 제출 전까지 채점하지 않는다
- **실기 체크리스트** — 장내기능·도로주행 점검 항목

## 개발
```bash
npm install
npm run dev            # 개발 서버
npm run build          # 프로덕션 빌드
node verify/verify.mjs # 문항 데이터 검증 (실패 0건이어야 한다)
```
